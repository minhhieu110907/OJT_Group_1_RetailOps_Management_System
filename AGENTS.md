2. Read the corresponding business rules.
3. Inspect the current implementation and database design.
4. Preserve security, authorization, and transaction invariants.
5. Do not introduce scope changes without Tech Lead approval.
6. Run relevant tests before reporting completion.

If documents conflict, report the conflict instead of guessing.
